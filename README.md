# Habit Tracker

A simple habit tracker web app built with AI tools for Engineering Design 2 (FAU).

> 🚧 Work in progress. Full documentation, deployed link, and demo video coming soon.

## Tech stack
- React + Vite (frontend)
- Supabase (database + authentication)
- Netlify (hosting)

## Local setup
```bash
npm install
cp .env.example .env   # then fill in your Supabase URL and anon key
npm run dev
```
